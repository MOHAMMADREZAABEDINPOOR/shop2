<a id="شروع-کار"></a>

## 🚀 شروع کار

PHP 8.3 یا بالاتر، Composer، Node.js 22.12 یا بالاتر، npm و دیتابیس تنظیم‌شده در .env.

<div dir="ltr">

```bash
git clone https://github.com/MOHAMMADREZAABEDINPOOR/shop2.git
cd shop2

composer install
# Copy .env.example to .env; configure DB_CONNECTION and credentials
php artisan key:generate
php artisan migrate --seed
# Seed only a fresh development database
npm ci
npm run build
php artisan serve
```

</div>

<a id="استفاده"></a>

## 🎯 استفاده

PHP 8.3 یا بالاتر، Composer و Node سازگار با Vite 8 نصب کنید. .env و دیتابیس را تنظیم، APP_KEY بسازید، دیتابیس توسعه را migrate و seed، فایل وب را build و Artisan را اجرا کنید. مسیرها در routes/web.php است.

<a id="استقرار"></a>

## 🌍 استقرار

فایل محیط واقعی، HTTPS، دیتابیس مستقل و میزبان مجاز تنظیم کنید. در PHP ریشه وب را public/ و در Django فایل استاتیک و WSGI/ASGI را تنظیم کنید. سرور توسعه برای میزبانی عمومی نیست.

<a id="محدودیت‌ها"></a>

## 📌 محدودیت‌ها

Seed کاربران نمایشی با گذرواژه معلوم می‌سازد؛ پیش از میزبانی عوض کنید. پرداخت و ایمیل به اتصال محیط واقعی نیاز دارند؛ مخزن تضمین تأییدیه تولید نیست.

<a id="رفع-مشکل"></a>

## 🛠️ رفع مشکل

- پکیج غایب: وابستگی را با مدیر پکیج پروژه نصب کنید.
- خطای API یا شبکه: آدرس، سرویس و اتصال میزبانی را بررسی کنید.
- فایل قدیمی: در صورت وجود اسکریپت ساخت، build و کش مرورگر را تازه کنید.

<a id="مشارکت"></a>

## 🤝 مشارکت

برای تغییر، شاخه مستقل بسازید، رفتار فعلی را بررسی کنید و توضیح روشن همراه تغییر بفرستید. اطلاعات خصوصی، خروجی build و دیتابیس محلی را commit نکنید.
